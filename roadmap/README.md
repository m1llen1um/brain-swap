# Roadmap

Feature candidates for brain-swap. None is scheduled. A candidate becomes work by updating `idea.md`, `PRD.md` and `TECHSPEC.md` to include it.

| Candidate | Summary |
|---|---|
| [Pane metadata](pane-metadata.md) | Show the card ID on the herdr pane border. |
| [WIP limit](wip-limit.md) | Limit the number of cards in the active columns. |
| [Other agent packs](other-agent-packs.md) | Command packs for agents other than Claude Code, on the same CLI. |
| [Archive of done cards](archive-done-cards.md) | Move done cards out of the board view so the done column stops growing. |
| [Manual card order](manual-card-order.md) | A stored order within a column that overrides the activity order. |
| [Notes from the TUI](tui-notes.md) | Write a switch note from inside the TUI with a key. |
| [Clipboard on jump fallback](clipboard-fallback.md) | Copy the working directory to the clipboard when the jump cannot focus a pane. |
| [Board label for /bs-card](board-label.md) | Choose the board with an explicit label instead of free text. |
| [Non-English input](non-english-input.md) | Define how labels and board choice behave for Bulgarian or Russian input. |
| [Drafts without invented facts](grounded-drafts.md) | Draft note parts only from what the conversation shows. |
